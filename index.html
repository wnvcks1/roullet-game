번호 패드 (누르면 바로 1개 추가)

요약

아직 기록이 없음. 위에서 번호를 입력하거나 플레이 탭에서 스핀하면 여기에 쌓임.

각 스핀은 서로 독립이라 이 통계는 다음 번호를 예측하지 못함. 표본이 적을 때의 쏠림은 대부분 우연임.

룰렛 종류

종류마다 기록이 따로 쌓임. 바꾸면 올려둔 칩은 환불됨.

기록 자동 채우기

배팅 없이 룰렛을 돌려 현재 룰렛 기록을 목표 횟수까지 채움. 스핀과 같은 난수 함수를 쓰고, 칩은 건드리지 않음.

분석 기록 초기화

버튼을 누르면 확인 문구로 바뀌고, 4초 안에 한 번 더 눌러야 실행됨.

보유 칩

입력한 값으로 보유 칩이 바뀌고, 올려둔 칩은 먼저 회수됨. 분석 기록은 그대로 유지됨. 최대 100,000,000.

난수 검증

스핀 결과는 브라우저 보안 난수(crypto.getRandomValues)로 현재 룰렛의 칸을 균등하게 뽑아 정함. 배팅액·보유 칩·이전 결과·설정을 보지 않음. 아래 버튼은 같은 추첨 함수를 10만 번 돌려 균등한지 검사함.
